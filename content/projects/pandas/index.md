## CausalMicrobiome

A computational pipeline for causal inference in microbiome studies. CausalMicrobiome integrates two-sample Mendelian Randomization with machine learning approaches to identify causal relationships between microbial taxa and host phenotypes in livestock systems.

### Features
- Two-sample MR analysis with multiple sensitivity tests (MR-Egger, weighted median, IVW)
- Integration with GWAS summary statistics
- Support for 16S rRNA and WGS metagenomic data
- Visualization of causal effect estimates and forest plots
- Batch processing across multiple phenotypes

### Applications
Applied to rumen microbiome data from beef cattle to identify microbial drivers of feed efficiency and methane emissions.
